# Slime Room Prototype

ブラウザで動く、スマホ向けスライムアクションの試作です。

## 起動方法

`index.html` をブラウザで開いてください。

## スマホ操作

- 左下の円形スティック：移動（斜め入力対応）
- ダッシュ：地上では長めの回避ダッシュ、空中では急降下
- ジャンプ：大ジャンプ、壁付近では壁ジャンプ
- ダッシュ中にジャンプ：通常より高く遠くへ飛ぶダッシュジャンプ
- ダッシュジャンプ中にダッシュ：進行方向へ斜め急降下（通常ジャンプ中は真下へ急降下）
- くっつき：壁への吸着、ダッシュ中に敵の足元で使うと転倒、空中で敵の頭付近に使うと顔へ吸着

ゲーム画面と操作エリアは上下に分離され、縦長スマホ・折りたたみスマホの横長画面に合わせて自動配置されます。

## PC操作

- 移動：矢印キー / WASD
- ダッシュ：Shift / X
- ジャンプ：Space / Z
- くっつき：C / E

## GitHub Pagesで公開

1. GitHubで新しいリポジトリを作成
2. このフォルダ内の `index.html`、`style.css`、`game.js` をアップロード
3. リポジトリの **Settings → Pages** を開く
4. **Deploy from a branch** を選ぶ
5. Branchを `main`、フォルダを `/ (root)` にして保存
6. 表示されたURLをスマホで開く

## v3 レイアウト修正

- ゲーム画面と操作盤をCSS Gridで完全分離
- ブラウザのアドレスバーを考慮する `100svh` 対応
- 左スティックが必ず操作盤内に残るよう最小幅を確保
- 縦長画面では右ボタンを2段、横長画面では横一列に配置
- GitHub Pagesで旧CSSが残りにくいよう、CSS/JSに更新番号を付与

公開後も旧表示のままの場合は、ページを再読み込みするか、Chromeのメニューから「再読み込み」を行ってください。


## v4 アクション追加

- ダッシュ中のジャンプを強化ジャンプへ変更
- ダッシュの進行方向を空中慣性として維持
- 強化ジャンプ中の急降下を斜め急降下へ変更
- 通常ジャンプ中の急降下は従来どおり真下
- 斜め急降下中も短い無敵時間あり

## v5 壁アクション・障害物

- 外周の壁と部屋内の障害物にくっつけるように変更
- くっつきボタンを離した後も約0.3秒の壁ジャンプ猶予
- 壁ジャンプは接していた面と反対方向へ飛ぶ
- 高い石柱と、ジャンプで越えられる低い木箱を追加
- 敵も障害物をすり抜けず、ぶつかると進行方向を変える


## v6 追加内容
- 敵の顔へ張りつくと、顔を覆う専用表示と気絶ゲージが出ます。
- くっつきボタンを約1.25秒押し続けると気絶します。ジャンプで途中離脱できます。
- 剣兵は近距離の広いなぎ払い、槍兵は長い直線突きを使います。
- 攻撃前に色付きの予告軌道が出ます。ダッシュ中の無敵時間で回避できます。
