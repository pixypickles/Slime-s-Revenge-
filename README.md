# Slime Room Prototype

スライム主人公の、1部屋制トップダウン・アクションゲーム試作です。ブラウザだけで動き、GitHub Pagesへそのまま公開できます。

## 遊び方

### PC
- 移動: 矢印キー / WASD
- ダッシュ: Shift / X
- ジャンプ: Space / Z
- くっつき: C / E

### スマホ
画面下の方向キーと3つのアクションボタンを使います。

## アクション

- 地上ダッシュ: 長めの高速移動＋短い無敵時間
- ダッシュ中、敵の足元で「くっつき」: 敵を転ばせる
- ジャンプ中にダッシュ: 急降下攻撃
- 空中で敵の近くにいる時に「くっつき」長押し: 顔を覆って気絶させる
- 空中で壁際に「くっつき」: 壁に張りつく
- 張りつき中、または離した直後にジャンプ: 壁ジャンプ
- 敵を全員気絶させる: 上の扉が開く

## GitHub Pagesで公開する方法

1. GitHubで新しいリポジトリを作る
2. このフォルダ内の `index.html` `style.css` `game.js` `README.md` をアップロード
3. リポジトリの **Settings → Pages** を開く
4. **Deploy from a branch** を選ぶ
5. Branchを `main`、フォルダを `/ (root)` にして保存
6. 数分後、GitHub PagesのURLでゲームを開けます

## ローカルで試す方法

`index.html` をブラウザで開くだけでも動きます。
