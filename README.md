# Slime Room Prototype

ブラウザで動く、スマホ向けスライムアクションの試作です。

## 起動方法

`index.html` をブラウザで開いてください。

## スマホ操作

- 左下の円形スティック：移動（斜め入力対応）
- ダッシュ：地上では長めの回避ダッシュ、空中では急降下。壺の中では方向入力と長押しで転がす
- ジャンプ：大ジャンプ、壁付近では壁ジャンプ
- ダッシュ中にジャンプ：通常より高く遠くへ飛ぶダッシュジャンプ
- ダッシュジャンプ中にダッシュ：進行方向へ斜め急降下（通常ジャンプ中は真下へ急降下）
- くっつき：壁への吸着、ダッシュ中に敵の足元で使うと転倒、空中で敵の頭付近に使うと顔へ吸着

ゲーム画面と操作エリアは上下に分離され、縦長スマホ・折りたたみスマホの横長画面に合わせて自動配置されます。

## PC操作

- 移動：矢印キー / WASD
- ダッシュ：Shift / X
- ジャンプ：Space / Z
- くっつき：C / E

## GitHub Pagesで公開

1. GitHubで新しいリポジトリを作成
2. このフォルダ内の `index.html`、`style.css`、`game.js` をアップロード
3. リポジトリの **Settings → Pages** を開く
4. **Deploy from a branch** を選ぶ
5. Branchを `main`、フォルダを `/ (root)` にして保存
6. 表示されたURLをスマホで開く

## v6 追加内容
- 敵の顔へ張りつくと、顔を覆う専用表示と気絶ゲージが出ます。
- くっつきボタンを約1.25秒押し続けると気絶します。ジャンプで途中離脱できます。
- 剣兵は近距離の広いなぎ払い、槍兵は長い直線突きを使います。
- 攻撃前に色付きの予告軌道が出ます。ダッシュ中の無敵時間で回避できます。


## v7 遺跡・壺

- 石柱を、上下が太い柱頭・柱礎と縦溝のあるギリシャ遺跡風デザインへ変更
- 床、外壁、扉を砂色の石造遺跡風へ変更
- 部屋に壺を2個追加
- 壺の真上へ着地すると中へ入り、敵から隠れられる
- 壺の中では敵がプレイヤーを追跡・攻撃しない
- ジャンプボタンで壺から飛び出せる

壺転がしと破壊処理は次のバージョンで追加予定です。


## v8 壺アクション正式実装

- 壺へ入った状態で、方向入力をしながらダッシュを長押しすると壺が震える
- 約0.38秒ためると、入力方向へ壺が高速で転がり始める
- 転がる壺は壁・柱・木箱・敵への最初の衝突で割れる
- 壺が割れると破片演出と画面振動が入り、スライムが反対方向へ飛び出す
- 剣兵は転がる壺を追い、攻撃範囲に入ると斬って破壊できる
- 槍兵へ壺を直撃させると一撃で気絶させられる
- 静止して壺に隠れている間は、従来どおり敵から発見されない
- ジャンプで壺から任意に飛び出す既存操作も維持
- 敵全滅による扉解放判定を、壺の中にいる場合にも正しく更新

### v8 操作

- 壺に入る：壺の真上へ着地
- 壺を転がす：方向入力＋ダッシュ長押し
- 壺から出る：ジャンプ


## v0.9 敵AI

- 敵が部屋内の決められた巡回地点を順番に見回る巡回行動を追加
- 敵ごとに視界距離と視野角を持たせ、視界内のスライムを発見すると追跡する
- 高い石柱が敵の視線を遮り、柱の裏へ回り込むと追跡を切れる
- 見失った敵は最後に見た位置へ向かい、周囲を一定時間捜索してから巡回へ戻る
- 壺へ入る瞬間を見られた場合、敵がその壺へ近づいて中を調べる
- 壺を震わせた音は近くの敵に聞こえ、壺の調査を誘発する
- 見られず静かに壺へ入った場合は、従来どおり安全に隠れられる
- 転がる壺に対する剣兵の迎撃と、槍兵への壺直撃効果を維持
- 発見中は「！」、捜索・調査中は「？」を敵の頭上へ表示
- 敵の視界を薄い扇形で表示し、ステルス行動を判断しやすくした
- 既存の移動、ダッシュ、ジャンプ、壁アクション、顔への張り付き、敵全滅での扉解放を維持

### v0.9 敵AIの流れ

巡回 → 発見・追跡 → 最後に見た場所を捜索 → 巡回へ復帰

壺は、入るところを見られた場合や中で震わせた場合だけ調べられます。

## v1.1 HP・回復システム

- プレイヤーの初期HPを5に設定
- 敵本体へ触れただけではダメージを受けないように変更
- 接触時はキャラクター同士が重ならないための押し戻しだけを行う
- 剣兵の剣、槍兵の槍、守護隊長の武器攻撃でのみHPダメージを受ける
- 通常兵の武器攻撃はHP1、守護隊長の攻撃はHP2ダメージ
- HPが0になると、最大HPまで回復して現在の部屋の入口から再挑戦
- 現在HP・最大HP・取得済み最大HP実を自動セーブへ追加
- v1.0の旧セーブデータから部屋進行を引き継げる互換処理を追加
- 敵を全員無力化するとゼリーの実が植物に実る
- 実の近くで「くっつき」を押すと吸収し、通常の実はHP1回復
- 色違いのゼリーの実は最大HPを1増加し、取得状態をセーブ
- キラキラした神秘の水壺へ入ると、各部屋で一度だけHP2回復
- 神秘の水壺も通常の壺と同様に、隠れる・転がす・破壊される処理を維持
- HP表示を画面左上へ追加

### ダメージのルール

敵の身体そのものは危険ではありません。剣の振りや槍の突きなど、予告された武器部分に当たった時だけHPが減ります。
